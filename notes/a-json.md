JSON is primarily a data format, but it is also used as a file type and a way to structure data storage.  

To clear up the confusion, think of JSON (JavaScript Object Notation) like this:  

1.  The Format (What it is): It is a specific set of rules for writing down text so that both humans and computers can easily read it.
2.  The File (How it's saved): When you write text using the JSON format and save it on your computer, it becomes a .json file. (Under the hood, it is just a plain text file).
3.  The Data Storage (How it's used): Because it is so organized, databases (like MongoDB) and applications use it to store and pass information back and forth.
4.  JSON became the gold standard because it is lightweight (uses less internet data) and works with every major programming language, not just JavaScript. 
5.  Instead of writing a long paragraph, you organize your information into clear key-value pairs
