### HTTP Methods:  

if we divide the  type of software we use based on interaaction -
1.  Static - interactive less btwn s/w n user, mostly on info basis like calender, clock
2.  Dynamic - more interactive like ms excel

we'll focus more on dynamic software.

Atmost dynamically we can interact with dynamic software is  of 4 types : **CRUD**
1.  Create : Adding new data - insert - POST
2.  Read : Viewing or retrieving data - select - GET
3.  Update : Editing existing data - UPDATE - PUT / PATCH

4.  Delete : Removing data - DELETE	- DELETE

Websites are a type of softwares where we use it on our machines but they are not installed on our systems unlike ms word, calender and clock 

the place where these special software is installed is called server, and where these softwares are installed is called client.

website :
1.  static : user less interacts with client.
2.  dynamic : user can interact aggressively like instagram.

we mention the type of interaction we want  with a website(server) along with the http request.   

1.  **GET** (Read/Retrieve): Asks the server to send back data
        opening google.com to fetch n view the search page
2.  **POST** (Create): Sends new data to the server to create a brand-new record
3.  **PUT / PATCH**(Update): Modifies data that already exists on the server.
	• PUT: Replaces the entire piece of data with a new version.
	• PATCH: Makes partial updates (like changing just a password, not the whole profile).
4.  **DELETE** (Delete): Tells the server to destroy a specific piece of data

### Path Parameters:

Path parameters are dynamic segments of a URL path used to identify a specific resource  

path parameters can be used to read,update and delete.
